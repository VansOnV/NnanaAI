## ✨ What is Nnana AI?

Nnana AI is a conversational modding assistant. Instead of digging through forums, decompiling scripts by hand, or piecing together outdated tutorials, you just **describe what you want in plain English** — and Nnana builds it for you, step by step, right inside the chat.

> "can u help me get 2 player splitscreen working for gta 5 on ps4"
> → Nnana analyzes the file structure, writes the camera + input logic, packages it, and hands you a ready-to-drop `.zip` — all inside one conversation.

No command line. No Discord servers full of dead links. No guessing which script is actually stable. Just chat, build, play.

---

## 🚀 Features

- **🗨️ Natural language mod building** — describe the mod, Nnana writes it
- **🔧 Built-in patching** — tell it something's broken and it re-diagnoses + fixes the build
- **📦 One-tap packaging** — every build ships as a clean, ready-to-install `.zip`
- **🖥️🎮 Cross-platform** — works for both **PS4** and **PC** builds of GTA V
- **📚 Chat history** — every conversation is saved so you can revisit old builds anytime
- **🧠 Model picker** — choose between speed-optimized and quality-optimized models depending on how complex your mod is
- **⚡ Real-time build visualizer** — watch each build step complete live instead of staring at a frozen terminal
- **💎 Nnana Pro** — unlimited builds & fixes, priority generation speed, advanced tooling access

## 💬 How It Works

1. **Open a chat** — start fresh or pick up an old one from your sidebar
2. **Describe the mod** — be as specific or as casual as you want
3. **Watch it build** — Nnana streams its progress step-by-step, live
4. **Download & play** — grab the packaged `.zip` straight from the chat
5. **Something off?** — just say so, and Nnana re-diagnoses and patches it

---

## 🧩 Tech Stack

Nnana AI's interface is built with:

- **HTML5 / CSS3** — fully custom dark-mode UI, no framework bloat
- **Vanilla JavaScript** — chat engine, streaming responses, multi-chat state
- **Web Vibration API** — native-feeling haptic feedback on supported devices
- **Blob / Object URL API** — instant client-side file packaging & download

No backend, no accounts required, no telemetry — everything runs locally in your browser.
